yuki 便携版 · 首次运行说明

1. 先解压到一个新文件夹（例如 D:\yuki\），不要直接在压缩包里双击。
2. 双击 yuki.exe 启动，她会出现在屏幕右下角。
3. 第一次用需要填 API Key：
   右下角她的输入框旁边有个齿轮按钮（或在托盘菜单里选"设置…"）
   → 在"DeepSeek Key"里填 sk- 开头的 key → 点"保存设置"。
   没有 key 的话她不会说话（大脑没连上），其他功能正常。
4. 想让她出声：设置 → 行为 → 打开"语音输出（说话）"。
5. 想把整个文件夹搬到别的电脑：整个文件夹拷贝走即可，记忆和设置都带着。
6. 数据都在 data\ 文件夹：聊天记忆、长期记忆、心情状态、日志、截图。
